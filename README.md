# climate-prediction

Multi-agent climate-change research system, built on
[orchestra](https://github.com/aaron-zhlg/orchestra).

Problem and agents are not defined yet.

## Setup

```bash
uv sync
```

Set one LLM key:

```bash
export DEEPSEEK_API_KEY=sk-...
# or OPENAI_API_KEY=...
# or ORCHESTRA_API_KEY + ORCHESTRA_BASE_URL + ORCHESTRA_MODEL
```
